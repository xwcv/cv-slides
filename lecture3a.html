HOG：方向梯度直方图

  • 用局部梯度方向直方图描述形状：cell 内统计梯度方向 → block 内归一化 → 按空间网格拼接
  • 直觉：不追踪精确的边缘坐标，但保留局部区域中的梯度方向分布——得到带粗粒度位置信息的形状素描
  • 经典组合：HOG + SVM——手工特征 + 浅层分类器
  • 行人检测的里程碑工作（Dalal & Triggs, 2005）
  • 行人相对刚性，适合用模板表达
记住：HOG + SVM 是深度学习之前视觉任务的标准范式——人工设计特征，机器学习只负责最后的分类器。
HOG 描述子与 SVM 权重可视化
图源：Dalal & Triggs, CVPR 2005
第 3 讲（上） · 手工特征时代07

HOG + SVM 行人检测

  • 典型范式：浅层特征 + 浅层分类器
  • 检测流程：滑动窗口扫描 → 每个窗口提取 HOG → SVM 打分
  • 在 EPFL / PETS2009 数据集上效果良好
  • 但模板固定，难以应对复杂变化
注意：这类方法的“智能”几乎全在人工设计的特征里，分类器本身很浅——特征一旦失效，整体就失效。

第 3 讲（上） · 手工特征时代08
Where hand-crafted assumptions break

手工特征不够鲁棒：真实变化往往超出设计假设

Occlusion遮挡

关键点或轮廓被挡住，描述子可能找不到稳定对应。

Illumination光照变化

阴影、曝光和局部反光会改变梯度与对比度。

Appearance / Pose外观与姿态

非刚体形变或姿态变化会破坏固定模板的匹配。

Viewpoint / Scale视角与尺度

超出预设范围的透视与尺度变化仍会改变局部结构。

注意：手工特征的“不变性”来自人工假设（如 SIFT 假设尺度 / 旋转不变）；开放世界中假设一旦不成立，特征就失效。
与其人工“设计”特征，
不如让机器从数据中学习表征。
—— 表征学习的出发点

第 3 讲（上） · 什么是好的表征12

LeCun 的蛋糕：自监督才是主体

  • 纯强化学习 = 樱桃：偶尔的几个比特奖励
  • 监督学习 = 糖霜：每样本 10~10,000 比特
  • 无监督 / 预测学习 = 蛋糕主体：每样本数百万比特
  • “比特”指标签携带的信息量——人工标签的信息远远少于数据本身
  • 智能的大部分来自对世界的预测式学习
注意：蛋糕是信息量的直观比喻，不是严格可测量的监督信号排序定律；它传达的动机是——人工标签的信息远少于数据本身，这是自监督兴起的根本动机。

第 3 讲（上） · 什么是好的表征13

好的表征应具备哪些性质？

输入 x目标信息 + 姿态、光照、背景等干扰
编码器fθ
表征 z保留任务需要的信息，减少无关变化
紧凑 compact

去除冗余，用更少维度表达有效信息。

充分 sufficient

没有丢掉完成下游任务所需的关键因素。

解耦 disentangled

姿态、光照等变化尽量由不同因素解释。

可解释 interpretable

人能理解维度、方向或区域与语义的关系。

记住：判断表征好坏的终极标准是“下游任务是否变容易”（Bengio, Courville & Vincent, IEEE TPAMI 2013）。这些性质依赖任务且相互制约——对分类无关的姿态信息，对姿态估计却是关键；紧凑、充分、不变、解耦、可解释不一定能同时满足。核心原则：保留任务需要的信息，抑制任务不需要的变化。
第 3 讲（上） · 什么是好的表征14
回应开场问题 2 · 哪些变化应被保留？

不变性与等变性：要保留什么，取决于任务

输入变化分类任务希望定位 / 几何任务希望
物体在图像中平移近似不变：仍判断为同一类别等变：预测位置应随之移动
水平翻转多数自然物体分类可保持类别文字、交通方向和左右解剖结构可能改变语义
颜色改变形状主导的类别可适度忽略细粒度识别、病理和材料检测可能必须保留
裁剪或遮挡可容忍非关键区域缺失过强裁剪会删除目标或几何关系
好的表征不是对所有变化都不敏感，而是对与任务无关的变化保持稳定，对任务需要的变化保留可预测响应。
依据：Bengio, Courville & Vincent, IEEE TPAMI 2013；SimCLR, ICML 2020

第 3 讲（上） · 浅层特征学习19

PCA：学习一组本征基向量

  • 寻找数据方差最大的一组正交基（本征表示）
  • 直觉：给高维数据找“主轴”，保留数据变化最大的方向
  • 以重建 / 压缩为目标的线性降维
  • 第一个本征脸对应最大方差方向，依次递减
  • 数据驱动，但只是线性、浅层的变换
注意：PCA 最大化投影方差，等价于最小化线性重建误差；“方差最大 = 信息量最大”只在特定分布假设下才成立，不能直接等同。且 PCA 是线性方法，只看二阶统计量；人脸角度、表情等非线性变化它表达不了。

第 3 讲（上） · 浅层特征学习21

稀疏表示：字典上的稀疏组合

  • 测试样本 = 训练字典的稀疏线性组合 + 稀疏误差
  • 求解 L1 最小化：min ‖x‖₁，s.t. Ax = y
  • 直观理解：用尽可能少的训练样本拼出测试样本，因此大部分系数为零
  • 遮挡 / 噪声被建模为稀疏误差项，因此对它们很鲁棒
记住：稀疏表示把遮挡当成稀疏误差显式建模，这是它在遮挡人脸识别上鲁棒的根本原因。
稀疏表示人脸识别：遮挡 / 噪声下仍可定位正确身份

回应开场问题 3 · 微调策略怎么选？

实践指南：线性探针、部分微调，还是全量微调？

策略什么时候选冻结与学习率怎么设典型风险
线性探针（全部冻结）标注极少（几十~几百张）；或目的是公平比较预训练表征编码器全冻结，只训练线性头；正常学习率即可对非线性任务欠拟合——低分不代表特征里没有信息
部分微调（解冻后几层）中等标注量；源域与目标域比较接近冻结底层（通用边缘纹理），解冻高层；高层用 1/10 学习率，新分类头可正常解冻层数过多 → 小数据上过拟合
全量微调标注较充足，或目标域与源域差异大（如医学影像、遥感）全网小学习率（如 1e-4），分类头可大 10 倍；配合较强增广灾难性遗忘、过拟合；小数据上慎用
对照实验纪律：一次只改一个因素（冻结层数 / 学习率 / 增广），固定数据划分与随机种子。识别负迁移：微调后不如从头训练，或验证集早早过拟合——先检查源域差距与增广是否破坏了任务语义。

策略选择

线性探针 / 部分微调 / 全量微调按标注量与域差距选择；一次只改一个因素做对照。

03
跨结构迁移

知识还能跨网络结构迁移（如 FNA++ 的参数重映射），但预训练仍依赖人工标注。

半监督学习：伪标签

  • 设定：少量标注数据 + 大量无标注数据
  • 用当前模型为无标注数据生成伪标签
  • 在“标注 + 伪标注”数据上重新训练，迭代提升
注意：伪标签会把模型的错误自我强化（确认偏差，confirmation bias）——实践中必须用置信度阈值过滤低质量伪标签。

FixMatch：弱增广出标签，强增广学一致

  • 弱增广图像的预测超过阈值 → 转化为 one-hot 伪标签
  • 强增广图像的预测与伪标签计算交叉熵
  • 核心：同一语义的不同视图应有一致预测
  • Sohn et al., NeurIPS 2020
记住：FixMatch 的分工——弱增广负责产出可信伪标签，强增广负责学习“扰动下预测不变”。
FixMatch：一致性 + 伪标签的统一框架
图源：Sohn et al., NeurIPS 2020

Mean Teacher：师生一致性

  • 学生网络正常梯度训练
  • 教师网络 = 学生参数的指数滑动平均（EMA）
  • θ′t = αθ′t−1 + (1−α)θt，α 接近 1（如 0.99），教师变化缓慢
  • 直观理解：教师是学生参数的长期平均，因此提供的学习目标更稳定
  • Tarvainen & Valpola, NeurIPS 2017
记住：一致性正则的核心假设——对输入做小扰动（增广 / 噪声 / 不同模型），预测结果不应改变。
Mean Teacher：教师由学生 EMA 更新，提供更稳定的目标
图源：Tarvainen & Valpola, NeurIPS 2017

本章小结：半监督学习

01
伪标签

模型自己给无标注数据“造”标签再自训；陷阱是确认偏差，需置信度阈值。

02
FixMatch

弱增广出标签、强增广学一致，把伪标签与一致性正则统一到一个框架。

03
Mean Teacher

教师 = 学生参数的 EMA，目标更稳定；一致性假设贯穿所有半监督方法。

Closing the Loop

回到开场：判断表征是否好用，先回答这四件事

开场问题现在应能给出的回答
1 · 学习信号区分人工设计、人工标签、预训练权重和数据内部关系分别提供了什么信息。
2 · 保留与忽略对任务无关变化保持不变；对位置、方向或细粒度属性等任务变量保留响应，必要时保持等变。
3 · 微调策略按标注量与源域差距选择线性探针、部分微调或全量微调；一次只改一个因素，警惕负迁移。
4 · 评价协议线性探针只看线性可分性；还要按用途检查检索、少样本微调、密集迁移、跨域表现和失败样例。
面对自己的任务，最后用三句话落地：希望表征保留什么、忽略什么、准备怎样验证。增广如何定义不变性、训练如何防止坍塌，见第 3 讲（下）。
特征可以从数据中学，也可以从旧任务借；
当标注真正稀缺时，
数据本身就是监督信号。
